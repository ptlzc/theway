# 翻译规则

[English](translation-rules.md) | 中文

创建或更新英文优先 crate 文档的中文对侧文件时，遵循本规则。英文定义默认源；译文保留相同的行为、限定条件和示例，同时使用自然的中文技术表达。

## 忠实度

- 翻译英文源中的每个条款，不增加行为、前提、警告、版本、示例或实现状态。
- 两种语言都描述当前机制，不叙述变更历史。
- 两侧内容冲突时，按需修正英文源，并在同一变更中同步中文对侧文件。

## 结构保持

- 保持标题层级与顺序、列表类型与条目数、表格行列以及强调 span。
- 围栏代码块必须逐字节相同，包括信息字符串、注释和换行。
- 行内代码、命令、flag、配置键、路径、API 名称、事件名、版本和数值保持原文。
- 两侧所有普通链接使用相同目标，并指向无后缀英文文档。Crate 文档中的仓库相对链接必须留在归属 crate 内；根目录或兄弟 crate 的概念只用文字描述，不建立链接。只有语言切换行使用 `.zh.md` 目标。

## 术语

- 已收录术语遵循 [terminology.md](terminology.md)。
- 未收录的技术术语没有明确通行译法时保留英文。
- 保留产品与协议的标准大小写，包括 GitHub、Rust、TypeScript、JSON-RPC、gRPC、MCP、SSE 和 WebSocket。

## 中文排版

- 中文与拉丁文字或数字之间使用一个半角空格。
- 中文正文使用全角中文标点；代码 span 内的标点保持不变。
- 使用直接、专业、主语明确的中文技术表达，每个段落占一个物理行。

## 评审与记录

- 记录 hash 前评审语义与语言；校验器无法判断翻译质量。
- 只有两侧同步后才运行 `scripts/verify-doc-i18n.py --write <source.md>`。
- 提交任何配对文档变更前运行 `make doc-sync`。
